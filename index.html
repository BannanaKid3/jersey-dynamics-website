01 / THE BUILD

Started with a stubborn prototype

We are building the evidence before the full robot.

A humanoid can become a collection of ambitious drawings very quickly. Jersey Dynamics starts smaller: build one subsystem, document what fails, measure what improves, and only then decide what deserves to scale.

The current hand uses two center fingers and two opposing thumbs. That layout is intentional: it tests useful grasping with fewer actuators and a simpler mechanical architecture.

How we work

Useful progress has receipts.

Every track should leave behind something another person can inspect, test, reproduce, or improve.

  1. 01
    Define the question

    Write the requirement, constraint, cost target, and interface before building.

  2. 02
    Make the smallest test

    Build only enough to answer the question cleanly.

  3. 03
    Record what happened

    Keep measurements, failures, decisions, and revisions—not just the final result.

  4. 04
    Release the learning

    Share the code, CAD, BOM, tests, and next problem.
